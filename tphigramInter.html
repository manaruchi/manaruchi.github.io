Interactive Tephigram

Exact sounding values

Bulk sounding entry

Paste rows as: Pressure, DB, DP. Commas, tabs, or spaces accepted. Leave a temperature blank if missing (use commas or tabs).

Thermodynamic points

Add independent LCL, LFC, EL, CCL or custom points. They do not join either sounding profile. Use the Reference tool and click a thermodynamic point to toggle its three curves.

Text annotations

Select the T icon, then click the chart to place text. Click or drag an existing label to select or move it. Text stays attached to its chart coordinates while zooming.

Plotted points

Use Set in the table, or select ◎ Set reference and click an existing plotted point. Multiple locked references are supported. Solid curves = locked references; dashed curves = live hover.
